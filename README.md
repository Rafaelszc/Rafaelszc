## ☕ About

I'm a Computer Science student at [UEPB](https://uepb.edu.br) and work at **NUTES** (Núcleo de Tecnologias Estratégicas em Saúde).
I like building full-stack apps with Spring Boot and React, small data tools in Python, and keeping my Linux setup tidy — dotfiles in [`my_configs`](https://github.com/Rafaelszc/my_configs).

Currently studying machine learning, data analysis and software architecture.
